# Ekaterina Prianichnikova — portfolio prototype

Static one-page portfolio site. Open `index.html` locally or publish the folder with GitHub Pages / Netlify / another static host.

## Files
- `index.html` — content and structure
- `styles.css` — responsive visual design
- `script.js` — subtle scroll reveals
- `assets/` — temporary images extracted from the existing portfolio PDF

The current build is a first working prototype. Replace temporary images with original high-resolution exhibition/project photographs before final publication.
